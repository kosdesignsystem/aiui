Твоя задача: Создать приложение Компоненты по гайдлайнам ./rules.md
Это приложение должно показывать внешний вид UI компонентов и давать контролы для управления вариантами этих компонентов
Приложение будет разбито на страницы: View, Modals, List, Controls. Пока делаем одну страницу

Страница 1: View

Варианты (На скринах)

Показать/Скрыть Верхний блок Actions
Выбрать вариант верхнего Actions

- Табы (с возможностью установки иконочной кнопки слева или справа)
- блок с иконочными кнопками
  Показать/Скрыть Нижний блок Actions
  Выбрать вариант нижнего Actions
- Кнопки (текст + иконка)
- Кнопки с текстом
- Поиск с возможностью установки иконочной кнопки слева или справа

Состояние скролла, когда Header скрывается, а верхний Actions фиксируется наверху страницы
