# Голос КОС

Диктофон доступен в каталоге NC по сохранённому адресу `/app/Focus/main`.
Таймер «Фокус» удалён и заменён на «Голос КОС». Удержание кнопки (или Space/Enter)
записывает микрофон, отпускание останавливает запись и отправляет её в GigaAM.
Через 24 секунды запись останавливается автоматически. Аудио можно прослушать,
скачать и повторно отправить, текст — отредактировать и скопировать.

## Почему нужен сервис

GitHub Pages раздаёт статические файлы и не исполняет Python/PyTorch.
В этом проекте находятся и интерфейс, и сервис, но размещаются они отдельно.
Без подключённого сервиса работает запись, а распознавание недоступно; приложение
сообщает об этом. Распознавание браузера и демонстрационные тексты не используются.

Сервис использует настоящую GigaAM `v3_e2e_ctc` с пунктуацией. Исходники модели
зафиксированы на `7447938d791c4f3e643386ee22c33777004293a5`. Официальный пример:
https://github.com/salute-developers/GigaAM#model-inference

## Запуск

Нужен Docker Compose на машине с доступом к GitHub, PyPI, серверу загрузки
PyTorch и CDN весов GigaAM. Первая сборка и загрузка весов займут время и место.
Производительность CPU зависит от машины; GPU-окружение здесь не настраивается.

```sh
cd services/voice-kos
# Необязательно для локального запуска; задайте для опубликованного сервиса:
export VOICE_API_TOKEN='replace-with-a-long-random-token'
docker compose up --build -d
curl http://localhost:8000/health
```

`/health` отвечает только после загрузки модели. Порт по умолчанию привязан к
localhost. Для удалённого подключения разместите сервис за HTTPS reverse proxy,
передающим `Authorization`, с ограничением размера запроса 5 МБ и таймаутом
распознавания 120 секунд. Включите ключ `VOICE_API_TOKEN`, прежде чем открывать
доступ к сервису в интернете. CORS ограничен `https://kosdesignsystem.github.io`;
для разработки задайте `VOICE_ALLOWED_ORIGINS=http://localhost:5173`.

В приложении нажмите настройки, введите адрес сервиса (например,
`https://voice.example.ru`) и тот же ключ. Адрес хранится в браузере,
ключ — только в памяти страницы. Отправка записи выполняется после отпускания
кнопки, только на указанный сервер. Перед публикацией адрес также можно задать
через `VITE_GIGAAM_API_URL` при сборке фронтенда.

Для локальной проверки откройте фронтенд через `npm run dev`, а сервис — по
`http://localhost:8000`. Доступ к локальному серверу с опубликованного сайта может
потребовать разрешения браузера на локальную сеть; HTTPS reverse proxy устраняет
зависимость от этой возможности браузера.

## API

`POST /transcribe`, multipart-файл `audio`, опциональный заголовок
`Authorization: Bearer <VOICE_API_TOKEN>`; ответ `{"text":"…","model":"v3_e2e_ctc"}`.
FFmpeg переводит WebM/Opus, MP4 и другие поддерживаемые контейнеры в PCM mono
16 kHz. Вход ограничен 5 МБ и 25 секундами (лимит `transcribe` GigaAM).
Одновременно выполняется одно распознавание, занятый сервер отвечает 503.
Временные файлы удаляются после обработки, приложение не сохраняет аудио/текст
в localStorage. Завершение сессии/уход со страницы выключает микрофон.

## Проверки API без скачивания весов

```sh
python -m pip install -r services/voice-kos/requirements-api.txt pytest httpx
python -m pytest services/voice-kos/test_app.py -q
```

Тесты проверяют API, декодирование настоящего аудио через FFmpeg и обработку
ошибок с подменённым распознавателем. Они не подтверждают качество модели.
Для проверки настоящего GigaAM запустите контейнер и отправьте короткую запись:

```sh
curl -H "Authorization: Bearer $VOICE_API_TOKEN" \
  -F 'audio=@speech.webm' http://localhost:8000/transcribe
```
