# Статус-бар и навбар: правила

Источник: спека дизайнера ОС «Статус-бар и навбар». Экран-эталон 360×800 dp.

## Роли
- ОС рисует только значки: время, сеть, Wi-Fi, батарея; «Назад» и «Домой». Камера — физический вырез, не рисуется.
- Приложение рисует всё под барами: заливку, картинку, видео, контент.
- Бары прозрачные всегда: без собственной заливки, градиента и блюра.

## Размеры (dp)
Берутся из `docs/system-bars/system-bars.tokens.json`. В коде приложений числа 40 и 48 не хардкодить, брать из системных инсетов.

## UI компонентов
Эталоны: `StatusBar.svg` (360×40) и `Navbar.svg` (360×64: 16 на скруглённые углы экрана и 48 сам навбар), лежат в `docs/system-bars/assets/`. Размеры и координаты слоёв в `docs/system-bars/system-bars.tokens.json`.
- Статус-бар: камера (подложка #212529 при 12%), время, индикаторы звонка (#24CE9F) и таймера (#8C8CFF), справа сеть, Wi-Fi, батарея. Без звука, будильник, авиарежим, GPRS в макете скрыты и стоят на координатах сети, Wi-Fi и батареи.
- Навбар: высота 48, три кнопки 100×48 с отступом 30 по бокам: «Назад» (центр x 80), «Домой» (x 180), «Обзор» (вертикальная черта, x 280). Иконки 24×24, #212529 при 52%.
- Правила показа скрытых индикаторов и состояния нажатия кнопок в макете не заданы.

## Режимы статус-бара и навбара (актуально)
У приложения два режима, выбирает приложение на экране:
- **Заливка** (по умолчанию). Шапка приложения закрашивает зону бара, градиента нет. Нужна для чистых светлых и однотонных экранов.
- **Наложение.** Контент (изображение, видео, прокрутка) идёт под бар. Градиента нет, ОС ничего не подкладывает под значки.

Цвет значков выбирает приложение: `light` (#FFFFFF) или `dark` (#212529). Выбор статичный для экрана и не зависит от прокрутки. В режиме «наложение» без выбора значки белые. В режиме «заливка» без выбора значки по теме системы. Навбар без своего `navBar.icons` повторяет цвет значков статус-бара; `auto` отключает повтор, значки по теме системы. Подложка выреза камеры: белый при 16% при светлых значках, #212529 при 12% при тёмных. Макет: `assets/StatusBar.svg`.

## Краевые случаи
- Шит не доходит до статус-бара: максимальная высота шита экрана минус 40 dp, содержимое внутри шита скроллится.
- Временный показ баров в полном экране: без градиента и затемнения.
- Чистый белый или однотонный контент: режим «заливка», не «наложение».
- Навбар: режимы те же, что у статус-бара, градиента нет.
- Шапка, которая уезжает при прокрутке: когда под баром появляется контент, включается режим «наложение», переход должен быть плавным.
- Ландшафт, окна не на весь экран, касания в зоне бара, «уменьшить прозрачность», индикаторы звонка и таймера на светлой шапке: правила пока не описаны.

## Цвет значков
- Светлый фон: `#212529`. Тёмный фон: `#FFFFFF`.
- Выбор по контрасту WCAG 2.1: считать относительную яркость фона под значками, взять цвет с большим контрастом. Граница примерно 0.18 (светлее — тёмные значки).
- Фон неоднородный (картинка, градиент): считать по самому светлому месту под значками.
- Нижний навбар окрашивается по тем же правилам, независимо от статус-бара.

## Контракт приложение → ОС
| Параметр | Значения | По умолчанию |
|---|---|---|
| `statusBar.mode` | `surface` · `overlay` (атрибут `data-status-bar-mode`) | `surface` |
| `statusBar.icons` | `light` · `dark` (атрибут `data-status-bar-icons`) | по теме системы; в `overlay` — `light` |
| `statusBar.visibility` | `shown` · `hidden` | `shown` |
| `navBar.mode` | `surface` · `overlay` (`data-nav-bar-mode`) | `surface` |
| `navBar.icons` | `light` · `dark` · `auto` | `auto`; в `overlay` — `light` |
| `navBar.visibility` | `shown` · `hidden` | `shown` |
| показ скрытых баров | свайп от края, бары временно поверх контента | включён |

## Паттерны
- **P1 Сплошная заливка.** Приложение закрашивает зону бара. Значки по цвету заливки. Нижняя панель и зона навбара — так же.
- **P2 Контент под барами.** Картинка/видео на весь экран. Значки по самому светлому месту под ними.
- **P3 Скролл под баром.** Защиту (если нужна) рисует приложение. Контент под баром не принимает нажатия. Значки по цвету защиты. Если контент не заходит под бар (список вкладок), защита не нужна, под баром сплошная заливка.
- **P4 Полный экран.** Оба бара скрываются вместе. Под камерой ничего важного.
- **P5 Показ скрытых баров.** Свайп от верхнего/нижнего края показывает оба бара. ОС кладёт под значки затемнение, бары скрываются сами.
- **P6 Вырез и отступы.** Верх 40, низ 48, камера слева Ø32. Интерактив в зону камеры не ставить.
- **P7 Шапка сжимается при скролле.** Открытие: полная шапка 54 pt, пока нет скролла не меняется. За первые 70 pt прокрутки сжимается до 36 pt (адрес по центру). Заливка шапки и нижней панели из цвета контента, значки по контрасту.
- **P8 Оверлеи.** Шит/диалог затемняет экран на 0.5, в том числе под бары. Значки статус-бара по затемнённому фону. Навбар над клавиатурой по цвету клавиатуры. После закрытия всё возвращается.

## Чеклист для ревью
- [ ] Нет собственной заливки у баров ОС.
- [ ] Цвет значков выбран по контрасту ≥ 4.5:1, не захардкожен «на глаз».
- [ ] Отступы берутся из инсетов.
- [ ] При скрытии прячутся оба бара, есть показ свайпом.
- [ ] Нижняя панель/навбар окрашены в тот же цвет, что шапка, либо по своему фону.
