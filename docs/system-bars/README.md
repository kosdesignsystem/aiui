# Статус-бар и навбар: правила

Источник: спека дизайнера ОС «Статус-бар и навбар». Экран-эталон 360×800 dp.

## Роли
- ОС рисует только значки: время, сеть, Wi-Fi, батарея; «Назад» и «Домой». Камера — физический вырез, не рисуется.
- Приложение рисует всё под барами: заливку, картинку, видео, контент.
- Бары прозрачные всегда: без собственной заливки, градиента и блюра.

## Размеры (dp)
Берутся из `docs/system-bars/system-bars.tokens.json`. В коде приложений числа 40 и 52 не хардкодить, брать из системных инсетов.

## UI компонентов
Эталоны: `StatusBar.svg` (360×40) и `new_Navbar.svg` (360×52), лежат в `docs/system-bars/assets/`. Размеры и координаты слоёв в `docs/system-bars/system-bars.tokens.json`.
- Статус-бар: камера (подложка #212529 при 12%), время, индикаторы звонка (#24CE9F) и таймера (#8C8CFF), справа сеть, Wi-Fi, батарея. Без звука, будильник, авиарежим, GPRS в макете скрыты и стоят на координатах сети, Wi-Fi и батареи.
- Навбар: две кнопки 52×52 со скруглением 12, «Назад» x 52, «Домой» x 154. Иконки #212529 при 52%.
- Правила показа скрытых индикаторов и состояния нажатия кнопок в макете не заданы.

## Статус-бар: значки и градиент (актуально)
По макету `assets/StatusBar.svg`: значки статус-бара всегда `#FFFFFF` и не подстраиваются под цвет контента. Читаемость держит собственный градиент бара: чёрный при 40% на верхней границе, 0 на нижней, высота 40 dp. Подложка выреза камеры: белый при 16%. Приложение статус-бар не красит и цвет значков не выбирает: параметр `statusBar.icons` больше не используется. Правила ниже про выбор цвета по контрасту относятся к навбару.

## Цвет значков
- Светлый фон: `#212529`. Тёмный фон: `#FFFFFF`.
- Выбор по контрасту WCAG 2.1: считать относительную яркость фона под значками, взять цвет с большим контрастом. Граница примерно 0.18 (светлее — тёмные значки).
- Фон неоднородный (картинка, градиент): считать по самому светлому месту под значками.
- Нижний навбар окрашивается по тем же правилам, независимо от статус-бара.

## Контракт приложение → ОС
| Параметр | Значения | По умолчанию |
|---|---|---|
| `statusBar.icons` | не используется: всегда `#FFFFFF` + градиент бара | — |
| `statusBar.visibility` | `shown` · `hidden` | `shown` |
| `navBar.icons` | `light` · `dark` · `auto` | `auto` |
| `navBar.visibility` | `shown` · `hidden` | `shown` |
| показ скрытых баров | свайп от края, бары временно поверх контента | включён |

## Паттерны
- **P1 Сплошная заливка.** Приложение закрашивает зону бара. Значки по цвету заливки. Нижняя панель и зона навбара — так же.
- **P2 Контент под барами.** Картинка/видео на весь экран. Значки по самому светлому месту под ними.
- **P3 Скролл под баром.** Защиту (градиент или блюр) рисует приложение. Контент под баром не принимает нажатия. Значки по цвету защиты. Если контент не заходит под бар (список вкладок), защита не нужна, под баром сплошная заливка.
- **P4 Полный экран.** Оба бара скрываются вместе. Под камерой ничего важного.
- **P5 Показ скрытых баров.** Свайп от верхнего/нижнего края показывает оба бара. ОС кладёт под значки затемнение, бары скрываются сами.
- **P6 Вырез и отступы.** Верх 40, низ 52, камера слева Ø32. Интерактив в зону камеры не ставить.
- **P7 Шапка сжимается при скролле.** Открытие: полная шапка 54 pt, пока нет скролла не меняется. За первые 70 pt прокрутки сжимается до 36 pt (адрес по центру). Заливка шапки и нижней панели из цвета контента, значки по контрасту.
- **P8 Оверлеи.** Шит/диалог затемняет экран на 0.5, в том числе под бары. Значки статус-бара по затемнённому фону. Навбар над клавиатурой по цвету клавиатуры. После закрытия всё возвращается.

## Чеклист для ревью
- [ ] Нет собственной заливки у баров ОС.
- [ ] Цвет значков выбран по контрасту ≥ 4.5:1, не захардкожен «на глаз».
- [ ] Отступы берутся из инсетов.
- [ ] При скрытии прячутся оба бара, есть показ свайпом.
- [ ] Нижняя панель/навбар окрашены в тот же цвет, что шапка, либо по своему фону.
