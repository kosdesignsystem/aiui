# Исследование: интерфейс звонков для ребенка 5 лет на смарт-часах

## Что важно для детей 5 лет

1. **Минимум текста, максимум визуальных опор**  
   В этом возрасте ребенок быстрее ориентируется по лицам, эмодзи, цветам и знакомым пиктограммам, чем по длинным подписям.
2. **Крупные зоны нажатия (не меньше 44×44 px, лучше больше)**  
   Детям сложно точно попадать по маленьким элементам на экране часов.
3. **Один главный сценарий на экране**  
   Основной путь — «выбрать родного → нажать позвонить».
4. **Явный статус и обратная связь**  
   Ребенок должен видеть, кого выбрал, и что будет после нажатия.
5. **Безопасность и контроль взрослых**  
   Ограниченный список контактов, быстрый SOS и минимум возможностей случайно «сломать» экран.

## Как это отражено в макете

- Главный экран содержит только семейные контакты в виде больших карточек.
- Карточки имеют:
  - эмодзи (быстрое узнавание);
  - короткое имя («Мама», «Папа»);
  - простую подсказку («Почитать сказку»).
- После выбора карточка подсвечивается, а ниже появляется крупная кнопка «📞 Позвонить».
- Дополнительные действия (голосовое, видео, SOS) вынесены в отдельные крупные кнопки внизу.

## Рекомендации для следующего этапа

- Добавить **озвучку подсказок** («Ты выбрал бабушку»).
- Ввести **защиту от случайного вызова**: удержание кнопки 1 секунду.
- Поддержать **автопереход на громкую связь** для маленького ребенка.
- Дать родителям экран настройки «белого списка контактов» и расписания доступности.
