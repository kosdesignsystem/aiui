# Добавление нового приложения (new-app)

Используй этот документ, когда приложения еще нет в `src/web`.

## Обязательный порядок

1. Создай структуру приложения:
   1. `src/web/<AppName>/v1/index.tsx`
   2. `src/web/<AppName>/v1/screens/`
   3. `src/web/<AppName>/v1/theme/`
   4. `src/web/<AppName>/v1/widgets/`
2. Перед реализацией экрана примени `component-first`:
   1. Проверь возможности `src/ui`.
   2. Проверь паттерны соседних приложений `src/web/*/vN`.
   3. Сопоставь макет с уже существующими компонентами.
   4. Сначала собери экран на существующих компонентах.
3. Если возможностей `src/ui` не хватает, остановись и запроси выбор пользователя:
   1. Расширить `src/ui` (обратно совместимо).
   2. Использовать локальные кастомные стили в `src/web/<AppName>/v1`.
4. После выбора пользователя реализуй экран(ы).
5. Обнови `src/web/registry.ts`.
6. Если в задаче есть новые компоненты/шаблоны/ассеты/анимации, дополнительно выполни `rules/new-asset.md`.

## Ограничения

1. Не дублируй существующие `src/ui`-компоненты локальными аналогами без выбора пользователя на шаге 3.
2. Не редактируй чужие приложения, если задача про создание нового.

## Чеклист

1. Новое приложение создано в `src/web/<AppName>/v1`.
2. Экран сначала попытались собрать на существующих `src/ui`-компонентах.
3. При дефиците функционала получен явный выбор пользователя.
4. `src/web/registry.ts` обновлен.
5. Учтены базовые рамки устройства `360x800`, верхний отступ `40`, нижний `52`.
