# Анимации

Здесь хранятся анимации переходов между экранами.

- Добавляйте новые файлы в формате `.scss`.
- Используйте единый нейминг: `slide-left`, `fade`, `scale-in`.
- Обновляйте список ниже при добавлении новых анимаций.

## Доступные анимации

- `fade`
- `slide-left`
- `slide-right`
- `noise` — анимированное зерно для скрытого (чувствительного) контента, класс `.animation-noise` в `noise.scss`
- `dissolve` — растворение пелены в частицы и обратная сборка (canvas, JS): `DissolveCanvas` в `src/web/SecureGallery/sensitive.parts.tsx`
