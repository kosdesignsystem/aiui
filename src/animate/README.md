# Анимации

Здесь хранятся анимации переходов между экранами.

- Добавляйте новые файлы в формате `.scss`.
- Используйте единый нейминг: `slide-left`, `fade`, `scale-in`.
- Обновляйте список ниже при добавлении новых анимаций.

## Доступные анимации

- `fade`
- `slide-left`
- `slide-right`
- `launcher-reveal` — мягкое появление экрана кода-пароля
- `launcher-home-in` — раскрытие домашнего экрана
- `launcher-shade-in` — вытягивание панели быстрых настроек
- `launcher-recents-in` — сборка карточек недавних приложений
