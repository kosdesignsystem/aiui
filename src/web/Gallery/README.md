# Галерея в member/AE

Исходник перенесён из `member/MK` (`acd81af428707eb2fc293e35ea85cf39dd49def4`):
`index.tsx`, `model.ts`, `header.tsx`, `nav.tsx`, `albums.tsx`, `albums.scss`,
`screen.tsx`, `screen.scss` и 23 изображения `src/assets/gallery/photo*.png`.
Существующие сетка, избранное, альбомы, просмотрщик, масштабирование и перелистывание
переиспользуются без переписывания. Общая библиотека `src/ui` не изменяется.

## Сценарий

- `/app/Gallery/all` — все общедоступные фотографии.
- `/app/Gallery/albums` — «Объект 1» первым, перед «Избранным».
- `/app/Gallery/albums?unlock=object-1` — Bottom Sheet ввода PIN.
- `/app/Gallery/protected` — «Объект 1» после успешной проверки `1234`.

Четыре цифры автоматически проверяются через 180 мс. При ошибке индикаторы
очищаются и появляется «Неверный код доступа». Поддерживаются экранные цифры,
физическая клавиатура, удаление и вставка в поле PIN. Закрытие: кнопка,
фон, Escape, свайп вниз за ручку или навигация браузера назад. При закрытии
фокус возвращается на карточку. Фон модального окна неактивен (`inert`).

12 различных иллюстративных фото вечеринки хранятся в
`src/assets/gallery/private-demo/`. Это стоковые демонстрационные изображения,
а не документальные снимки Beer Party Club. Исходные URL и ID Unsplash сохранены
в `sources.json`. Даты/подписи фотографий — демонстрационные.

Сетка и просмотрщик используют `PhotoScreen`: тап открывает фото,
горизонтальный свайп, стрелки клавиатуры и нижняя лента переключают кадры;
«Назад»/Escape закрывают просмотрщик. Кнопка «Назад» из альбома возвращает
к альбомам и уничтожает допуск. Перезагрузка, прямой URL, переход из меню
без успешного PIN и повторный вход через историю браузера не дают доступа.

## Граница демонстрации

Это UI-прототип, **шифрование файлов не реализовано**. В проекте не найдены
защищённое хранилище ключей и механизм шифрования медиа. PIN сравнивается
с демонстрационной константой в коде; не записывается в localStorage,
sessionStorage, cookies или историю браузера. Одноразовый допуск хранится
только в оперативной памяти страницы; в истории остаётся лишь его идентификатор.

Список закрытых фото вынесен в динамически загружаемый `protected-photos.ts`.
Он не импортируется в общую медиатеку, избранное, поиск или обложки. Запросы
изображений начинаются только после проверки PIN. Карточка использует
декоративные изображения из общей медиатеки, не из закрытого альбома.

Однако файлы являются **общедоступными статическими ассетами сборки**;
их можно получить по прямым URL или через инструменты разработчика.
Динамический импорт и проверка маршрута не являются защитой информации.
Не помещать в эту демоверсию реальные закрытые фотографии.

Для production нужны шифрование файлов, защищённое хранение ключей,
безопасная проверка PIN с ограничением попыток и управление сроком жизни
расшифрованных данных. Простое хеширование четырёхзначного PIN в браузере
не решает задачу защиты.

## Публикация

Существующий workflow `.github/workflows/deploy-pages.yml` уже публикует
`member/AE` в `/aiui/ae/`. После отдельно разрешённого commit/push Галерея
будет доступна по `/aiui/ae/#/app/Gallery/albums`. В ходе этой задачи
commit/push не выполняются.

## Проверки

`npm run build` собирает приложение, в том числе с `VITE_BASE_PATH=/aiui/ae/`.
Полная проверка TypeScript имеет 53 уже существующие ошибки в исходной ветке
в Camera/Calculator и React Native-коде; в файлах Gallery ошибок не выявлено.

Пройдено 23 сценарных DOM-проверки (React StrictMode + MemoryRouter):
положение карточки, отсутствие закрытых фото до входа, открытие модалки,
неверный PIN/очистка/удаление, Escape, повторное открытие, успешный вход,
12 уникальных фото, просмотр/стрелки/возврат, повторная блокировка и история,
отказ при прямом URL, исходное избранное и медиатека, отсутствие записи в
localStorage/sessionStorage. Геометрия и Web Animations замоканы;
эти проверки не подтверждают визуальную точность и работу реальных жестов.
Полноценная проверка браузером не выполнена: среда блокирует запуск Chrome
(`socket() failed: Operation not permitted`). Перед публикацией требуется
визуальная проверка на устройстве/в браузере: светлая и тёмная темы,
360×800 и мобильный viewport, свайп фото и закрытие модалки за ручку.
