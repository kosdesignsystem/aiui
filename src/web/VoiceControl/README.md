# VoiceControl

Демонстрационный экран: `/#/app/VoiceControl/main`.

`main.tsx` показывает рабочий стол на существующих обоях и иконках Launcher.
Нажатие иконки открывает локальный предпросмотр приложения. Сам помощник
не привязан к этому экрану: `VoiceControlHost` подключён в `AppScreen`
для всех зарегистрированных маршрутов, внутри рамки устройства на desktop
и поверх экрана на мобильных устройствах. Страницы других приложений не изменены.

## Как проверить

1. Нажмите «Помощник» внизу экрана.
2. Нажмите микрофон и выберите демонстрационную фразу — появятся
   прослушивание, распознанный текст, обработка и карточка результата.
3. Для текстового ввода нажмите «Написать команду»; отправьте текст
   кнопкой со стрелкой или Enter. Примеры доступны в раскрывающемся списке.
4. Закройте панель крестиком, Escape или нажатием вне неё.
   Текущий экран и его состояние сохраняются.
5. Повторите на другом экране, например `/#/app/test1NT/main`.

## Команды

- «Поставь будильник на 7:30» — 07:30, завтра.
  Также поддерживается время в формате `8:35` или `8 35`; неверное время отклоняется.
- «Напомни мне позвонить завтра в 12:00» — карточка напоминания.
- «Включи тёмную тему» — подтверждение настройки без изменения реальной темы.
- «Открой настройки» — подтверждение без реального перехода.
- «Напиши Анне: буду через 10 минут» — предпросмотр, отмена и демонстрация отправки.
- «Позвони Анне» — демонстрация вызова.
- «Какая погода завтра?» — демонстрационные погодные данные.
- Неизвестная команда — ошибка с действиями «Повторить» и «Другой запрос».

## Границы реализации

`model.ts` содержит чистый демонстрационный обработчик; его можно заменить
адаптером реальных действий. `overlay.tsx` отвечает за состояния, отмену
таймеров, удержание/возврат фокуса, inert-подложку и учёт Visual Viewport.
Анимации находятся в `src/animate/voice-control.scss` и учитывают
`prefers-reduced-motion`. Локальное оформление использует токены ДС.
Кнопки, иконки и поле ввода переиспользуются из `src/ui`.

Микрофон, распознавание речи, API, отправка сообщений, звонки и реальные
системные действия не используются. Данные не сохраняются между перезагрузками.
Экранная клавиатура учитывается через Visual Viewport; поведение на физическом
мобильном устройстве требует отдельной проверки.
