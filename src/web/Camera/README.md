# Camera

Маршрут: `/#/app/Camera/main`. На этом этапе реализован UI двух состояний
по референсам: основной экран и быстрые настройки по кнопке слева сверху.
Это одна страница; переключение панели не меняет маршрут и сохраняет состояние.

Используются готовые `App`, `IconButton`, `Icon`, `SegmentedTabs`.
Оформление локализовано в `main.scss`, общая библиотека компонентов не изменена.
Пять недостающих иконок добавлены в `src/assets/icons`, анимации —
в `src/animate/camera.scss`. Превью — отдельное статическое изображение,
подготовленное из существующего референса; сетка рисуется интерфейсом.

## Что можно проверить

- Кнопка слева сверху открывает и закрывает настройки; Escape закрывает панель.
- Основной экран: «Фото» / «Портрет», вспышка, миниатюра, затвор, смена камеры.
- Вспышка переключается по кругу: Авто (белая молния и серая A) → Выключена
  (белая перечёркнутая молния) → Включена (жёлтая молния) → Авто.
- Настройки: «Теплота», «Выдержка», «Формат», «Сетка».
- Сетка скрыта во время отображения настроек и учитывает переключатель после
  закрытия панели. Формат перебирает подписи 4:3, 16:9, 1:1.
- Теплота и выдержка пока только выбираются; регулировки будут добавлены позже.
- Затвор показывает короткую демовспышку, смена камеры зеркалит статическое превью.
- Реальная камера, сохранение файлов и открытие галереи пока не подключены.
  Доступ к оборудованию не запрашивается.

Учтены рамка 360×800, системные отступы 40/52, мобильная высота, безопасная
область снизу, клавиатурная навигация и prefers-reduced-motion. Цвет системной
оболочки адаптируется локально для Camera; остальные приложения не затронуты.
