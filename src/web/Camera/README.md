# Camera

Маршрут: `/#/app/Camera/main`. Реализован UI по референсам: основной экран,
быстрые настройки по кнопке слева сверху, регуляторы выдержки и теплоты.
Это одна страница; переключение панели не меняет маршрут и сохраняет состояние.

Используются готовые `App`, `IconButton`, `Icon`, `SegmentedTabs`.
Оформление локализовано в `main.scss`, общая библиотека компонентов не изменена.
Пять недостающих иконок добавлены в `src/assets/icons`, анимации —
в `src/animate/camera.scss`. Превью — отдельное статическое изображение,
подготовленное из существующего референса; сетка рисуется интерфейсом.

## Что можно проверить

- Кнопка слева сверху открывает и закрывает настройки; Escape закрывает панель.
- Основной экран: «Фото» / «Портрет», вспышка, миниатюра, затвор, смена камеры.
- Режимы съёмки работают как горизонтальный барабан: выбранная подпись плавно
  перемещается в центр. Поддерживаются нажатие, перетаскивание мышью, свайп,
  колесо/трекпад и клавиатура. На концах список не зацикливается.
- Вспышка переключается по кругу: Авто (белая молния и серая A) → Выключена
  (белая перечёркнутая молния) → Включена (жёлтая молния) → Авто.
- Настройки: «Теплота», «Выдержка», «Формат», «Сетка».
- Сетка включается и выключается кнопкой в настройках и видна также при открытой
  панели. Включённая кнопка жёлтая. Линии делят именно текущий кадр на три равные
  части по горизонтали и вертикали; за пределами кадра линий нет.
- Формат переключается 4:3 → 1:1 → 16:9 → 4:3. Подписи соответствуют референсу,
  сам кадр вертикальный: 3:4, квадрат, 9:16. Размер и обрезка изображения
  действительно меняются с сохранением пропорций. Для 1:1 остаются чёрные поля,
  а 16:9 заполняет высокий кадр с полупрозрачными настройками поверх фото.
- Формат и сетка независимы от общего сброса: не вызывают жёлтый индикатор
  настроек и кнопку «Сбросить», сохраняются при сбросе теплоты и выдержки.
- «Выдержка» открывает горизонтальный барабан: исходное значение «Авто»,
  движение влево затемняет демонстрационное фото, вправо осветляет.
  Поддерживаются мышь, touch, горизонтальное колесо/трекпад и клавиши стрелок.
  Значение сохраняется при закрытии контрола и повторном открытии.
- В этом UI-демо ручной диапазон −3…+3 с шагом 0,1 управляет яркостью превью
  через CSS brightness; это не установка физических секунд выдержки оборудования.
- Крестик закрывает контрол без сброса, правая круговая стрелка возвращает
  только выдержку в «Авто». Escape закрывает контрол с возвратом фокуса.
- При изменении теплоты или выдержки значок настроек становится жёлтым
  и появляется общий «Сбросить». Он восстанавливает только эти два параметра,
  скрывается и возвращает обычный цвет значка; выбор настройки без изменения
  значения не считается изменением параметра.
- Режим вспышки независим: не включает индикатор изменённых настроек
  и не меняется при общем сбросе. Положение значка настроек фиксировано
  независимо от наличия кнопки «Сбросить», текст сброса без подчёркивания.
- Риски барабана выдержки чередуются одна через одну: высокая серая и короткая
  тёмно-серая. Они сплошные, без внутренних белых полос и кружка; центральный
  указатель остаётся жёлтым и самым высоким.
- «Теплота» открывает сине-оранжевый ползунок с белой ручкой. По умолчанию
  ручка по центру (0), влево — холоднее, вправо — теплее. Поддерживаются
  мышь, touch, клавиатура и колесо/трекпад. SVG-матрица цвета меняет баланс
  красного/синего в демопревью и сочетается с независимой яркостью выдержки.
  Крестик закрывает контрол без потери значения, правая стрелка сбрасывает
  только теплоту в центр. Общий сброс сохраняет текущий режим вспышки.
- Затвор показывает короткую демовспышку, смена камеры зеркалит статическое превью.
- Реальная камера, сохранение файлов и открытие галереи пока не подключены.
  Доступ к оборудованию не запрашивается.

Учтены рамка 360×800, системные отступы 40/52, мобильная высота, безопасная
область снизу, клавиатурная навигация и prefers-reduced-motion. Цвет системной
оболочки адаптируется локально для Camera; остальные приложения не затронуты.
