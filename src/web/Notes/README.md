# Заметки — демо голосового ввода

Маршрут: `#/app/Notes/main`. Приложение зарегистрировано в общем реестре без изменения стартового экрана существующих приложений.

## Сценарий

1. Открыть страницу по HTTPS в браузере с Web Speech API.
2. Нажать микрофон и разрешить доступ к микрофону компьютера.
3. Говорить по-русски: предварительные результаты сразу отображаются в заметке, подтверждённые сохраняются в черновик.
4. Нажать микрофон повторно для остановки. При остановке браузером можно начать новую диктовку; текст добавляется к черновику.
5. Клавиша удаления стирает последний символ; удержание повторяет удаление. Удаление во время диктовки сначала останавливает распознавание: поздние результаты не восстанавливают удалённый текст.

Черновик сохраняется локально в текущем браузере (`aiui-notes-draft-v1`); при запрете localStorage работает в памяти вкладки. При скрытии вкладки и уходе с экрана диктовка останавливается. Остальные экранные клавиши и действия панели в демо отключены.

## Распознавание

Используются `SpeechRecognition` / `webkitSpeechRecognition`, язык `ru-RU`. Это браузерный движок, **не GigaAM**; своего сервера и API-ключей нет. Поддержка и доступность сервиса зависят от браузера, ОС и сети. Chrome может передавать аудио своему сервису распознавания; офлайн-работа не гарантируется. Интерфейс обрабатывает отказ в доступе, отсутствие микрофона, ошибки сети, отсутствие речи и неподдерживаемый браузер.

Реальное распознавание необходимо проверить вручную на компьютере с микрофоном. Автоматические проверки с подставным Web Speech API проверяют обработку событий и редактирование, а не качество распознавания или разрешения ОС.

## Общая клавиатура

`src/ui/Keyboard.tsx` / `Keyboard.scss`: `voiceState`, `status`, `onMicrophone`, `onDelete`, необязательный `onKey`. Компонент не запрашивает микрофон самостоятельно и не хранит заметку. Без `onKey` остальные клавиши отключены. Используются существующие шрифты и SVG из `src/assets`; ассеты не удаляются и не заменяются.

Основа внешнего вида — два предоставленных скриншота. Полная карта Pixso не была доступна без входа, поэтому соответствие её дополнительным состояниям пока не подтверждено.
