# Заметки — GigaAM в браузере

**Основной режим: откройте https://kosdesignsystem.github.io/aiui/ae/#/app/Notes/main и нажмите микрофон.** Homebrew, Python, localhost и отдельный сервис для этого режима не нужны.

Распознаёт настоящий GigaAM `v3_e2e_ctc` (ревизия `7447938d791c4f3e643386ee22c33777004293a5`) в ONNX Runtime Web 1.23.2 через WebAssembly. Аудио не отправляется на сервер. Страница скачивает файлы модели и движка; инференс выполняется в Web Worker на устройстве.

## Сценарий

1. Нажать микрофон. При первом запуске загрузится модель (~307 МиБ) и запустится движок. Прогресс показан над клавиатурой. Это может занять заметное время.
2. Разрешить микрофон. Произнести фразу до 20 секунд, повторно нажать микрофон для завершения раньше.
3. Текст появляется **во время речи**: примерно каждые 0,9 секунды накопленного аудио запускается распознавание нарастающего фрагмента. Реальная задержка включает время вычисления модели и зависит от устройства. Последние слова и пунктуация могут уточняться. После остановки обрабатывается оставшийся звук.
4. Новый промежуточный результат заменяет гипотезу текущего сеанса, а не дописывается повторно. Уже существовавший текст заметки сохраняется. Можно дописать следующую фразу или стереть символы клавишей удаления/удержанием. Удаление во время сеанса отменяет его и завершает Worker, чтобы поздний результат не вернул удалённый текст.

Модель остаётся в Worker для повторной диктовки; части модели кэшируются через Cache API при доступной квоте. Перед использованием проверяются длина и SHA-256 каждого файла. При запрете/переполнении кэша распознавание продолжает работать, но следующая загрузка может потребовать сеть. Полная офлайн-загрузка страницы не гарантируется: Service Worker для всего сайта не добавлялся.

Черновик хранится в localStorage. Скрытие вкладки и уход с экрана отменяют активный сеанс и закрывают микрофон. Остальные клавиши демонстрационные. Исходные ассеты сохранены. Полная карта Pixso не была доступна без входа.

## Устройство и браузер

Нужны HTTPS (или localhost для разработки), WebAssembly SIMD, Web Workers, Web Audio и разрешение на микрофон. Рекомендуется актуальный настольный Chrome. На устройствах с малым объёмом памяти или несовместимым движком модель может не запуститься; браузерный Web Speech API и серверы распознавания как запасной вариант не используются. GitHub Pages не позволяет выставить COOP/COEP, поэтому WASM работает с одним потоком; скорость зависит от устройства. WebGPU в этой версии не используется.

## Сборка модели

`scripts/export-gigaam-web.py` загружает официальные веса, экспортирует GigaAM с эквивалентным log-mel препроцессором (Conv1d DFT вместо неподдерживаемого STFT), квантует только MatMul линейных слоёв в INT8 и проверяет результат на официальном `example.wav`. Затем разбивает модель на файлы по 24 МиБ для размещения в gh-pages. Промежуточные `.onnx` не входят в публикацию. Веса и runtime не загружаются внешним CDN при открытии демо — они публикуются вместе с сайтом.

Workflow `.github/workflows/deploy-pages.yml` выполняет этот экспорт только для `member/AE` и кэширует результат. Обычные обновления интерфейса используют кэш. В исходную ветку добавляется код подготовки; бинарные части модели публикуются сборкой в gh-pages, а не коммитятся в source.

Для локальной разработки Python нужен только разработчику для подготовки весов:

```bash
python3 -m venv .venv-gigaam
.venv-gigaam/bin/python -m pip install -r local/gigaam/requirements.txt
.venv-gigaam/bin/python scripts/export-gigaam-web.py
npm ci
npm run build
npm run preview -- --host 127.0.0.1
```

В `dist/ort` копируются соответствующие версии WASM и MJS ONNX Runtime. `public/models/` — генерируемая папка, исключённая из source git. Старый локальный Python-сервис сохранён в `local/gigaam` для отдельных экспериментов, но интерфейс его больше не вызывает; [его инструкция](../../../local/gigaam/README.md). Старый `speech.ts` также сохранён и не используется.

## Проверки

Проведён настоящий браузерный smoke-тест: Chromium 133, микрофон с контрольным русским WAV, загрузка INT8 GigaAM, выполнение ONNX Runtime WASM и вывод русского текста в заметку. Проверены удаление и отсутствие POST-запросов с аудио. Это отличается от проверок с подставными ответами. На официальном полном примере текст INT8 совпал с PyTorch в данном тесте; это не оценка WER и не гарантия скорости на других устройствах.

## Вывод во время речи

Это периодическое распознавание нарастающих фрагментов обычной CTC-моделью GigaAM, а не отдельная потоковая модель. Одновременно выполняется только один инференс. Пока он занят, звук продолжает записываться; следующий запрос получает свежий снимок, без очереди старых снимков. При остановке приложение дожидается текущего запроса и уточняет фразу по всей записи. Лимит одного сеанса по-прежнему 20 секунд. Удаление, скрытие вкладки и отмена сохраняют уже видимый текст и игнорируют поздние результаты.

Проверки адаптера: `node --test local/gigaam/client.test.mjs`. Включают промежуточный вывод до остановки, единственный запрос в работе, пропуск устаревших снимков, финальный остаток аудио и отмену. Реальный браузерный тест с русским WAV также проверяет появление текста при активном микрофоне.
