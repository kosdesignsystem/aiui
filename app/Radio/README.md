# Radio

Самостоятельное Flutter-приложение радиоприёмника, перенесённое из web-прототипа
`/nc/#/app/Radio/main`.

## Запуск

### Онлайн без установки Flutter

После успешной публикации ветки `member/NC` приложение доступно по адресу:

<https://kosdesignsystem.github.io/aiui/nc/radio/>

GitHub Actions автоматически проверяет, собирает и публикует Flutter Web-версию
при каждом push в `member/NC`. До слияния этих настроек в ветку ссылка возвращает
404, потому что каталога `radio` ещё нет в опубликованной сборке.

### Локально

```sh
flutter pub get
flutter run -d chrome
```

Приложение загружает популярные станции из Radio Browser. Если сервис временно
недоступен, используются встроенные станции SomaFM. Для воспроизведения потока
нужен доступ в интернет.

## Структура

- `lib/main.dart` — тема и точка входа;
- `lib/models` — модель радиостанции;
- `lib/services` — каталог станций и управление аудио;
- `lib/screens` — экран радиоприёмника;
- `lib/widgets` — переиспользуемые элементы интерфейса;
- `lib/theme` — дизайн-токены и типографика.
- `web` — оболочка для запуска и сборки Flutter Web.

Другие платформы при необходимости можно добавить без изменения исходного кода:

```sh
flutter create --platforms=android,ios,macos,windows,linux .
```
