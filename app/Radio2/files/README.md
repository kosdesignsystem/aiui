# Radio2

Нативный Flutter/KPA-перенос React-приложения `src/web/Radio`.

Приложение показывает шкалу FM, загружает до 30 популярных станций из
Radio Browser и воспроизводит выбранный интернет-поток. Если каталог станций
недоступен, используются встроенные станции SomaFM.

## Сценарий

1. После запуска отображается первая встроенная станция.
2. Каталог Radio Browser загружается в фоне через три зеркала.
3. Ползунок и боковые кнопки меняют станцию.
4. Главная кнопка запускает или приостанавливает поток.
5. При смене станции активное воспроизведение продолжается автоматически.
6. Ошибка потока отображается сообщением `Поток недоступен`.

## Проверка

Из каталога `files`:

```sh
flutter pub get
dart format lib
flutter analyze
```

Сборка KPA выполняется скриптом соответствующей архитектуры из дерева
KasperskyOS for Mobile SDK.
