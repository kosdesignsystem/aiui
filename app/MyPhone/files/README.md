# MyPhone — Flutter web и KasperskyOS/KPA hand-off

Общая Flutter-реализация `src/web/MyPhone`, подготовленная для браузерного тестирования и передачи команде KasperskyOS for Mobile. Пакет Dart называется `my_phone`, каталог приложения — `app/MyPhone/files`. Интерфейс не использует WebView, React или исходный JavaScript во время работы.

Вход этапа 2 — текущее состояние `app/MyPhone` от 26 октября 2026 года поверх Git commit `68f098d2aeebe4307d33eb15f8c098fe718eece4`. Каталоги `app/MyPhone` и `src/web/MyPhone` не были добавлены в Git на момент подготовки, поэтому commit сам по себе не воспроизводит выбранную версию: перед передачей нужно закоммитить весь каталог приложения.

## Требования

- macOS;
- Flutter 3.41.1 stable и Dart 3.11.0 либо совместимая стабильная версия Flutter с Dart 3;
- Google Chrome для команды `flutter run -d chrome`.

В проекте сохранён диапазон SDK базового KOS-шаблона: `>=2.12.0 <4.0.0`. Версия `flutter_svg` зафиксирована как `1.1.6`, чтобы не повышать минимальный Dart SDK ради web-превью.

Текущий `pubspec.lock` создан Flutter 3.41.1/Dart 3.11.0 и фиксирует Dart `>=3.8.0`. Версия Flutter/Dart целевого KasperskyOS SDK в доступном окружении неизвестна. Перед KPA-сборкой разработчики должны выполнить разрешение зависимостей штатным Flutter из KOS SDK, проверить совместимость `flutter_svg 1.1.6` и зафиксировать получившийся lockfile. Не следует молча удалять SVG-поддержку или заменять оригинальные ассеты.

## Подключение к KasperskyOS SDK

1. Поместите или подключите каталог `app/MyPhone` как `examples/projects/mobile/kpa/my_phone` в дереве KasperskyOS for Mobile SDK. Если используется другой путь, синхронно обновите `PACKAGE_PROPERTY(PREFIX)` в `Config.in`.
2. Подключите `Config.in` и `my_phone.mk` штатным способом дерева SDK и включите `KB_examples_projects_mobile_kpa_my_phone` в конфигурации целевой архитектуры.
3. Проверьте, что доступны `components/flutter`, `include(platform/flutter)`, `PUB_HOSTED_URL` и `PUB_CACHE`.
4. Из окружения SDK выполните разрешение зависимостей и затем штатную сборку нужной архитектуры. Имена скриптов базового шаблона:

```sh
./cross-build.x86_64-pc-kos.sh
./cross-build.aarch64-kos.sh
```

Фактическую рабочую директорию и поддерживаемые скрипты нужно сверить с установленной версией SDK. Ожидаемое имя пакета — `lk.my_phone.kpa`, но фактический артефакт в текущем окружении не создавался.

## Платформенный контракт

Общий UI получает `MyPhonePlatformAdapter` через конструктор `MyPhoneApp`/`MyPhoneScreen`.

- `lib/platform/my_phone_platform.dart` — контракт и детерминированный браузерный `DemoMyPhonePlatformAdapter` без аппаратного I/O.
- `lib/platform/default_platform_adapter.dart` — условный экспорт: web-сборка (`dart.library.html`) выбирает демо-адаптер, а нативная/KOS-сборка — KOS-реализацию.
- `lib/platform/kos_platform_adapter.dart` — намеренно незавершённый KOS-stub. До интеграции с API целевого SDK он выбрасывает `UnsupportedError` при аппаратной операции, поэтому неподдерживаемые функции не маскируются локальным состоянием.

Команде KOS необходимо реализовать и внедрить:

- мобильные данные и Wi‑Fi;
- режим полёта, геолокацию и беззвучный режим;
- фонарик;
- системную громкость и яркость;
- переход в системные настройки.

До этой интеграции состояния шторки работают только в браузерной демонстрации и не управляют устройством. В KOS-сборке открытие шторки безопасно, но изменение переключателя, громкости, яркости или переход в системные настройки требует готового адаптера.

## Сценарии для проверки

1. На экране блокировки проведите вверх.
2. Введите любые четыре цифры — откроется домашний экран.
3. Проведите по домашнему экрану влево и вправо: на первой странице находятся шесть запускаемых приложений, на второй — исходные недоступные ярлыки.
4. Нажмите «Камера», «Телефон», «Погода», «Файлы», «Настройки» или «Галерея», дождитесь анимации запуска и нажмите системную кнопку «Домой» внизу.
5. На домашнем экране или в приложении проведите вниз: откроется шторка. Проверьте мобильную сеть, Wi-Fi, четыре быстрых переключателя и ползунки громкости/яркости. Проведите вверх или нажмите нижнюю область, чтобы закрыть её.
6. В шторке нажмите «Перейти в настройки» — автономный адаптер откроет оригинальное превью «Настроек».
7. На домашнем экране или в приложении проведите вверх: откроются недавние приложения. Листайте карточки горизонтально, смахните карточку вверх, откройте карточку нажатием или нажмите «Закрыть все».

## Ресурсы

Все runtime-ресурсы находятся в `assets/` и явно зарегистрированы в `pubspec.yaml`. PNG, исходные SVG и шрифты скопированы побайтно. Inline-SVG ручки разблокировки и динамических значков сети извлечены механически из JSX; их `viewBox`, пути, прямоугольники, радиусы, градиент, цвета, штрихи и окончания линий сверены с исходной разметкой.

Источники, способы переноса и SHA-256 записаны в `assets-manifest.json`. Проверка из корня репозитория:

```sh
python3 .agents/skills/web-to-flutter/scripts/verify_assets.py \
  app/MyPhone/files/assets-manifest.json \
  --repo-root . \
  --app-root app/MyPhone/files
```

## Демо-адаптеры и ограничения

- Сетевые, геолокационные, звуковые, фонарные, яркостные и громкостные операции в браузере представлены воспроизводимыми локальными состояниями; аппаратные службы не вызываются, значения сбрасываются после перезапуска.
- Исходная кнопка «Перейти в настройки» ведёт во внешний React-маршрут `/app/Components/navigation`, которого нет в автономном приложении. Web-адаптер открывает оригинальный экран-превью «Настроек» внутри MyPhone.
- Запускаемые приложения и экран недавних используют исходные статические PNG-превью — так же, как React-источник. Остальные ярлыки намеренно недоступны, поскольку в исходнике у них нет `preview`.
- Время `13:52` и дата «Понедельник, 24 июня» зафиксированы, как в исходном сценарии.
- Визуальное сравнение и сравнение скриншотов не выполнялись по правилам этапа.
- WOFF2-шрифты `KasperskySansText` нужно проверить в Flutter-движке целевого SDK. Если формат не поддерживается, разработчикам нужен исходный TTF/OTF того же семейства и начертания; подмена похожим шрифтом недопустима.
- SVG с `currentColor`, градиентом и штрихами проверены в браузере через `flutter_svg 1.1.6`; поддержку рендерером KOS необходимо подтвердить отдельно.
